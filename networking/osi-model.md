# OSI Model
The Osi model is the conceptual framework that divides Network communication into 7 layers.
#Layers
1.Physical layers
2.Data link layer
3.Network layer
4.Transport layer
5.session layer
6.Presentation layer
7.Application layer
## What I understand

### Layer 1 - Physical
Transmits raw bits over a physical medium.

Examples:
- Ethernet cable
- Fiber
- Radio signals

### Layer 2 - Data Link
Handles communication between devices on the same local network.

Examples:
- MAC addresses
- Ethernet
- Switches

### Layer 3 - Network
Responsible for logical addressing and routing.

Examples:
- IP addresses
- Routers

### Layer 4 - Transport
Provides end-to-end transport.

Examples:
- TCP
- UDP
